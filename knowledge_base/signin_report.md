# Unexpected sign-in or MFA report

## Purpose

Fictional Alder Works training procedure. Use when a user reports an unrecognized sign-in, unexpected MFA request or possible account compromise.

## Initial Information to Collect

1. What time and application were involved?
2. Did the user approve the request or enter credentials?
3. Are other users reporting the same activity?

## User-Safe Actions

1. Do not approve an unexpected authentication request.
2. Record the time and application without sharing authentication secrets.
3. Contact the designated security team through the approved reporting channel.

## Technician Actions

1. Preserve the reported timeline and user interaction details.
2. Send the report to the designated security team.
3. Only authorized security or identity staff may perform containment or account remediation.

## Escalation Criteria

Escalate operational outages, unknown scope, missing approvals, repeated faults or any action outside technician authority. Security reports always require designated security review. Building access and camera changes require their designated owner.

## Resolution Criteria

Keep the ticket open until an authorized person records an observed successful test. Suggested checks are not completed actions.
