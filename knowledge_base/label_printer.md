# Label printer support

## Purpose

Fictional Alder Works training procedure. Use for missing, unreadable, misaligned or offline shipping and office labels.

## Initial Information to Collect

1. Which printer, workstation and location are affected?
2. What exact error and label application are involved?
3. Can other users print, and is shipping blocked?
4. When did this start and what changed?

## User-Safe Actions

1. Confirm the selected printer name without changing settings.
2. Record the visible display error and label condition.
3. Ask whether another workstation can print to the same device.
4. Record whether shipping can continue with an approved alternative.

## Technician Actions

1. Compare the affected workstation and printer with a known working setup.
2. Collect driver and label application versions using approved tools.
3. Coordinate authorized queue, driver or calibration changes with the device owner; do not alter label content.
4. Prepare the error, timestamps, device ID and observed checks for vendor escalation.

## Escalation Criteria

Escalate operational outages, unknown scope, missing approvals, repeated faults or any action outside technician authority. Security reports always require designated security review. Building access and camera changes require their designated owner.

## Resolution Criteria

Keep the ticket open until an authorized person records an observed successful test. Suggested checks are not completed actions.
